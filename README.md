# Eastern Emergency Services · Sitio web

Landing page de Eastern: traslado asistencial básico (TAB), traslados programados,
cobertura de eventos y formulario **Agenda tu cita** que abre WhatsApp al **310 860 4590**.

Sitio estático (HTML + CSS + JavaScript, sin compilación). Para publicarlo en Vercel:
importar el repositorio y desplegar con la configuración por defecto.
